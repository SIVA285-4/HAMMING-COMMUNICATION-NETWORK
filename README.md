# HAMMING-COMMUNICATION-NETWORK
This project implements a Hamming (7,4) Error Detection and Correction Communication Network using Verilog HDL.

The design demonstrates how digital data can be transmitted through a communication channel, how a single-bit error can be introduced during transmission, and how the receiver can detect and correct the error using Hamming code.

The project is divided into four main functional blocks:

Data → Hamming Encoder → Error Injection Channel → Hamming Decoder → Corrected Data

The complete design is integrated into a top-level module and verified using a Verilog testbench.
